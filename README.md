# Análise do Salário Mínimo e Inflação (IPCA)

## 📌 Sobre o Projeto

Este projeto foi desenvolvido em **JavaScript** e executado no terminal utilizando **Node.js**.

O sistema permite consultar informações sobre a evolução do salário mínimo brasileiro e do índice de inflação (IPCA) entre os anos de 2010 e 2020, além de realizar uma comparação entre o crescimento salarial e a inflação de cada período.

O objetivo do projeto é praticar conceitos fundamentais de programação, como estruturas de repetição, condicionais, arrays de objetos, manipulação de strings e cálculos percentuais.

---

## 🚀 Funcionalidades

* ✅ Listar os salários mínimos de 2010 a 2020
* ✅ Listar os índices de inflação (IPCA) de 2010 a 2020
* ✅ Comparar o crescimento do salário mínimo com a inflação
* ✅ Exibir dados formatados no terminal
* ✅ Menu interativo para navegação

## ⚙️ Como Executar

### Pré-requisitos

* Node.js instalado

Verifique a instalação:

```bash
node -v
npm -v
```

### Instalação

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install readline-sync
```

### Executando o Projeto

```bash
node index.js
```

## 🎯 Objetivo do Projeto

O projeto busca demonstrar, de forma simples e prática, a evolução do salário mínimo brasileiro em comparação com a inflação acumulada em cada ano, permitindo uma análise básica do ganho real de renda ao longo do período.
